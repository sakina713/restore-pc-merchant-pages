# PC商家端交付验收

只核对本次授权范围。任务为规则维护时不运行Figma设计检查；Figma静态原型与真实可运行功能分别验收。

## 需求与证据

- [ ] 当前范围、平台、目标节点及证据优先级明确；仅数据变化或单字段微调未被错误拆成独立需求。
- [ ] PRD相关原型图、图注和步骤已阅读，字段/文案逐项对应；有图即在分析明细引用原型，无图不留占位。
- [ ] 需代码比对时先定位有效仓库和版本，原页结构与本次差异可追溯；用户批准的截图基线已记录。
- [ ] 已找到最匹配页面模板及原子组件；修改页未用不相干模板替代未变内容。
- [ ] 新增/修改/复用/删除准确归类；重复无变化页面不重复出稿，不遗漏关键弹层、状态和组内新增功能。

## 实例、内容与颜色

- [ ] 按 [内容完整性](content-integrity.md) 核对全部目标画板，表头、每行数据和各状态操作均正确。
- [ ] 原子按钮、表单、Tab、选择组、标签、表头和单元格仍为实例；无自由文本覆盖、手画近似控件或整页截图交付。
- [ ] 未改区域保留，获准修改的导航/标题已同步；固定侧栏宽度未被挤压。
- [ ] 无默认Tab/身份切换/筛选/操作残留，无非图标空按钮；隐藏完整容器后已回流。
- [ ] 普通字段不用状态标签；真实状态及开关类型正确；可点击蓝色保留，非交互高亮主色，主按钮是正确主色变体。
- [ ] 筛选入口不重复，状态使用合适选择控件，初始有值亦显示选中态；Tab不需要数量时关闭数字属性。
- [ ] 操作列数量、顺序、文案、颜色和可用性全部匹配，业务列无残留编辑/删除；未仅修改首行。
- [ ] 已绑定现有变量，截图真实色正确；已选值非placeholder灰，正文/说明与状态色未误换。
- [ ] 字体使用目标规范或本次授权替代；标题字重、模块Medium、适用概览数字MiSans未丢失。
- [ ] 同类新视觉已建局部组件，母版置于对应画板上方，重复项使用实例；没有为换文案脱离原子实例。

## 层级、间距和长内容

- [ ] 同页全部同级模块共用标签/内容/说明列边界，不只修红框；总开关先于受控设置。
- [ ] 强关联8px、同模块16px、跨模块24/32px；新增按钮距条目8px。原子内部规格与选项组32px未被误覆盖。
- [ ] 行内文字、控件、图标、单位、按钮垂直居中，必要的标题实例留白按许可校正。
- [ ] 说明可与正文同字号但次级色，靠近所属控件、远离下组；标题后数量与标题紧邻。
- [ ] 卡片左右16px、上下12/16px按适用密度；无需固定值的文本/标题Hug，正文及编辑区Fill。
- [ ] 长公式/规则按任务提供多行空间，长规则上下布局且可自适应高度；没有固定高度截断、半幅表格、长字段/按钮溢出。
- [ ] 表格自适应父容器或合理横向滚动，最右列/分页完整；数据多时未压缩成迷你比例。
- [ ] 页面标题后和抽屉头部无无效大白块，隐藏模板占位后已回流。
- [ ] AI渐变、活动提示等只在对应场景，正文不被装饰抢占；活动文案按PRD、0.5px描边、无阴影图标角标及灰2操作。

## 弹层与交互

- [ ] 弹窗居中、抽屉贴右，保留标题/Slot/底部组件；简单内容不无效嵌套，复杂内容随内容撑高。
- [ ] 底部主次操作右对齐，验证方式切换在左侧并同行居中；隐藏底部仍留40px安全距离。
- [ ] 整体任务提示可用通知组件，字段说明/错误仍在字段旁，不混用。
- [ ] 表单按钮32px高、间距8px；图标按钮的项目尺寸例外未推广到全部按钮。
- [ ] 需要的默认/已选/禁用/加载/空/失败/成功状态齐全，且不为未知业务凭空新增状态。
- [ ] 原型导航中的入口、切换、返回、关闭、取消和下一步均核对；只有实际连接才声称可点。
- [ ] 后端验证/上传/识别/短信/保存是否真实实现如实说明，不拿导航替代安全校验。

## 分析稿与画布

- [ ] 分析稿有总览、页面明细及页面结构图；原型图与说明比例合适，多步缩略图不截断且未降低原图清晰度。
- [ ] 页面结构图按 [专门规范](page-hierarchy.md) 验收，复用节点灰色且就近连接来源，编号正确对应明细。
- [ ] 无孤立箭头、断线、穿字或错位；最后一次几何变化后已截图查看。
- [ ] 画板直接置于画布、行内顶齐，水平120px、行间按最高画板底边320px；弹层紧随触发页。
- [ ] 模块索引720×880px、白字Noto Sans SC Bold 88px、文本宽528px、四边48px、顶部左对齐自然折行。
- [ ] 业务画板名无模板/解绑等制作信息；封面为库实例且位于最后一页，团队/文件位置按本次约定。
- [ ] 更改说明用指定组件/建议气泡，未修改的原文与用户已手改内容保留。

## 最终验证

- [ ] 按 [视觉规范](design.md) 和适用专题检查，确认没有互相冲突的项目参数。
- [ ] 已实际查看目标宽度截图，修正溢出、留白和对齐；真实前端另验可达性、滚动和交互。
- [ ] 本项目要求移动端输出时，按指定移动端设计稿和字段核对，不机械缩小PC版；不引入其他聊天的报告/品牌取色规则。
- [ ] 交付链接指向真实文件/节点，说明完成项与限制，不夸大完成范围。
