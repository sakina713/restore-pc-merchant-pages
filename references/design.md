# Lingo PC 组件与页面规范

本规范源自项目 Storybook 与 Figma 组件库，适用于同一组件体系的 PC 后台页面；本机仓库按名称定位，不依赖固定路径。这里只定义样式基线，不授权新增助手端等业务范围；当前明确要求及目标组件属性优先。

## 使用方式

1. 先复用对应组件，再按本文件选择尺寸、状态和布局。
2. 颜色、圆角、间距必须使用既有设计 token；不要新增近似值。
3. 页面表现不完整时，补齐默认、悬停、选中、禁用、空/加载/错误等与需求有关的状态。
4. 对宽表保留横向滚动和冻结列；不要把列压缩成不可读的迷你表格。

## 基础 Token

| 语义 | Token | 值 |
|---|---|---|
| 主色 / 选中 | `--color-primary` | `#19C1AD` |
| 主色悬停 / 禁用 / 浅底 | `--color-primary-hover` / `--color-primary-disabled` / `--color-primary-light` | `#47CDBD` / `#A3E6DE` / `#E3FCF9` |
| 主文本 / 次文本 / 弱文本 / 占位 | `--color-black` / `--color-gray-1` / `--color-gray-2` / `--color-gray-3` | `#1B1F29` / `#595D6A` / `#8B8F9B` / `#B4B8C2` |
| 边框 / 分割线 / 页面背景 / 模块底色 | `--color-gray-4` / `--color-gray-5` / `--color-gray-6` / `--color-gray-7` | `#E3E5EB` / `#EBEBEE` / `#F5F5FA` / `#F8F9FD` |
| 成功 / 警示 / 信息 / 错误 | `--color-success` / `--color-warning` / `--color-info` / `--color-error` | `#00AE74` / `#FF7605` / `#1277FF` / `#F74A4A` |
| 状态浅底 | `--color-success-bg` / `--color-warning-bg` / `--color-info-bg` / `--color-error-bg` | `#E5FEF4` / `#FFF4E6` / `#EAF2FF` / `#FEEEEE` |
| 组件 / 容器圆角 | `--radius-component` / `--radius-container` | `4px` / `8px` |
| 基础间距 | `--spacing-xs` / `--spacing-small` / `--spacing-medium` | `4px` / `8px` / `16px` |
| 默认字号 | `--font-size-base` | `14px` |

标题或强调信息可以增大；普通按钮、表单、筛选、导航、表格文案默认均为 `14px`。Header 公司名称和弹层标题使用 `16px`。

- 页面、弹窗、抽屉标题保留库组件的加粗字重；模块小标题使用Medium，不把所有标题改成Regular。概览关键数字优先MiSans加粗，需确认字体可加载；字体不可用时按本任务授权降级，不静默改字体。

- **高亮与链接分开**：非可点击但需突出的待匹配金额、金额合计、已选数量等使用品牌主色变量 `--color-primary`，不使用链接蓝；普通非交互正文仍用主文本或次级文本色。可点击字段/操作保持链接蓝，真实状态与警示/错误保持各自语义色。不得仅因数值重要就套用蓝色链接样式，也不得将原本可点击的蓝色字段改为主色。

## 页面骨架与滚动

- 页面高度等于视口，不出现整页垂直滚动；顶栏下的 Nav、二级侧栏和内容区在各自区域内滚动。
- 主结构为 `Header + (Nav + 内容区)`；有二级侧栏时为 `Nav + SecondarySidebar + MainContent`。
- Nav 与二级侧栏间距为 `0`；二级侧栏与主内容区间距为 `16px`。
- 页面内容区域右侧留 `16px`、底部留 `24px`；避免无意义的左侧留白。
- Nav 菜单区域内部滚动，折叠按钮固定在底部。二级侧栏默认宽 `200px`；收起后宽 `16px`，只显示展开/收起按钮，无内容、无右分割线。
- 使用 Auto Layout/Flex，内容区设置 `min-width: 0`、`min-height: 0`。长内容使用换行、省略或容器滚动，不重叠、不溢出。

## 容器、标题与数据卡

- 内容容器使用白底；页面背景使用灰 6；弱分组/数据卡底色使用灰 7。容器圆角 `8px`，普通控件圆角 `4px`。
- 模块标题要清楚但克制，禁止营销页式大标题和装饰性渐变。
- 新建或明确要求调整的内容区使用字号、字重和有语义的区域底色区分页面、模块、正文及说明的层级，不把所有信息做成相同权重。多段设置使用组件库带小竖条的模块标题；总开关独立置于其控制的下级设置之前。未改区域仍以源码为基线，不因此重排。
- 内容关系间距：强关联元素 `8px`，同模块内容组 `16px`，跨模块 `24px` 或 `32px`。新增按钮与对应已有条目保持 `8px`，使用局部分组承载；行内元素垂直居中。此规则不替换原子组件内边距和单选/多选项间 `32px` 的既有规格。
- 新增布局间距优先4px倍数；用户给定组件规格、0.5px描边及明确例外不因此被机械取整。
- 说明文字可与正文同为 `14px`，通过灰2等次级文字变量区分；距对应控件/条目 `8px`，距其他内容组 `16px`、其他模块 `24px` 或 `32px`。必须核对截图中的实际字色与分组归属，不能只验证变量绑定存在。
- 标题后数量、状态或短补充说明紧跟标题，强关联间距8px；不把同属标题的信息漂到行中间。标题与操作同行时，允许调整实例可覆写的布局留白（例如去掉8px顶部留白）以垂直居中，但不改库母版或控件高度。
- AI结果等明确的AI区域可使用局部、低饱和蓝紫渐变表达识别/生成属性；普通后台模块不套用装饰渐变。活动提示独立遵循原型，后续确认的样式为8px圆角、0.5px细描边、无阴影、无图标/角标、克制单色系渐变；文案不自行改写，操作默认灰2。
- 活动提示放在触发/适用字段或需求条目后，横向轻量布局，标题→规则明细，日期/条件按原文分行；可有同色系中等字重，不做强促销数字、贴纸或复杂插画。展示态用纯文本，不用输入框、白色子条或嵌套编辑控件。只有原型提供查看活动等操作才展示。该区域可按确认的品牌方案用独立渐变，不强制生硬套平台色。
- 数据卡普通样式：白底、细边框、`24px` 内边距；明细样式：灰 7 底、`16px` 内边距。关键数值 `26px / 600`，名称 `12px` 弱文本。
- 可跳转数据卡：灰 7 底、`4px` 圆角、`16px` 内边距；同组横向排列，超出时横向滚动。

## 按钮、输入与选择

| 组件 | 规范 |
|---|---|
| Button 默认 | 高 `32px`，左右内边距 `12px`，图文间距 `4px`，字号 `14px`，圆角 `4px` |
| Button small / large | `24px / 12px`；`40px / 16px` |
| Primary | 主色填充、白字；悬停使用主色悬停；禁用使用主色禁用 |
| Secondary | 白底、灰 4 边框、主文本；悬停边框主色 |
| Text action | 透明底、信息蓝；危险操作用错误红 |
| Input / Selector | 高 `32px`、左右 `12px`、灰 4 边框、圆角 `4px`、默认 `14px` |
| Hover / Focus / Open | 输入、选择器边框主色 |
| Disabled | 灰 7 底、灰色文本、不可操作 |
| Placeholder | 灰 3；已选值为主文本 |

- 单选/复选/开关使用组件实例：Radio `16px`；Switch `40×22px`。
- 二元开关使用 Switch 或 Checkbox；互斥选择使用 Radio；多选使用 Checkbox 或多选 Selector。
- 多选 Selector 内标签高 `22px`、字号 `12px`；标签间距沿用该选择器组件规格。选项组的32px不能误套到已选标签内部。
- 筛选栏：控件间距 `8px`，上下留白 `8px`，默认带灰 4 边框和容器圆角；纯页面筛选可使用无边框变体。搜索框最小宽 `180px`。
- 页面级操作通常在右上角，不混入筛选行；表单填写页按模板保留底部操作位置。按钮高32px、组间距8px、宽度随文字自适应，不无故改40px/16px。弹层底部规则见下节，不能用页面表单默认覆盖。
- 单选/多选成组优先引用完整组选项组件，项间32px；不要仅用最原子圆点/方框和自由文字手拼。标签按内容Hug，前/后缀图标显隐由组件属性管理。
- 有真实字数上限时启用组件的字数限制属性并改计数分母，不在placeholder另造计数器；无上限不显示假上限。

### 筛选组入口

- 对已有筛选组，优先使用组件库的完整筛选组件；也可在自适应排列的筛选控件组最前方引用“图标 + 筛选”按钮实例。若完整筛选组件已包含该入口，不重复添加按钮。
- 用户指定的按钮参考：[筛选按钮（节点 73:13436）](https://www.figma.com/design/SJZb0Bb7gxi8pjXlrqAFMZ?node-id=73-13436)。实际引用前读取该节点，确认实例及来源；保留原图标、文案、变体、尺寸和颜色变量，不手画近似按钮。
- 按钮与后续筛选控件同行，垂直居中，间距 `8px`；宽度不足时按组件支持的方式换行或调整容器，不能挤压、遮挡最右侧操作。
- 业务筛选项的字段、顺序、数据和显隐仍按 PRD/源码核对。此入口作为筛选组控件单独计数，不算新增业务筛选字段；不由入口推导新的高级筛选弹窗、条件或提交行为。

## Tab、Tag、Badge 与状态

- Tab 高 `48px`，内容纵向留白 `10px`，相邻间距 `8px`。
- 圆形筛选 Tag 高 `32px`，圆角 `40px`，内边距 `6px 12px`；未选中白底灰边，选中主色白字。
- 状态必须表达语义：成功用绿、风险/拒绝用红、待处理/警示用橙、信息/链接用蓝、无效/撤回用灰。不得只为“好看”换色。
- 表格内状态可使用浅色状态底+语义色文字；不要用大面积高饱和色块。
- 非状态普通字段不用标签；Tab无数量时关闭数量属性，不能留空括号。详细内容断言见 [内容完整性](content-integrity.md)。

## 表单

- Form 行间距 `16px`；单个 FormItem 最小高 `48px`。
- 横向表单：Label 与控件间距 `32px`，Label 高 `32px`。同一表单的单控件必须共用统一视觉列宽；推荐由容器定义变量，而不是为每项临时设宽。
- 纵向表单：保留原子表单组件内部规格；自由组合的 Label、控件与关联说明按强关联 `8px` 分组。说明文案可与正文同为 `14px`、使用次级文字色，不强制缩为 `12px`。
- 弹窗内表单控件应填满控件列；复杂组合输入可单独排网格，但首列与其他控件起点对齐。

## 规则编辑页专项规范

- **模板外壳与业务内容分开核对**：规则编辑采用用户指定的“设置规则页/编辑”等页面模板；保留规则名称、应用范围、规则内容和底部操作的位置关系，把本次原型的全部可编辑设置放入模板的规则内容框。不能把模板示例详情原样留下，也不能把编辑设置放到框外。未明确要求场景规则时，隐藏整个“新增场景规则”入口及其说明、占位；不需要的“默认规则”标题可隐藏并回流。不得连带删去原型要求的业务条目新增入口。
- **整页同级模块一起对齐**：当本次要求统一设置区布局时，先列出全部同级模块，确定共用标签列宽、标签到内容列间距和内容列左右边界，再逐模块应用。短输入、任务卡片、文本域及其说明不能各自从不同起点排布；不能修完一个模块就默认其他模块通过。规则页采用左右列时，自定义说明/优先级偏好等长文本模块同样使用左标签、右文本域，关联说明放在右列下方。长标签在固定列宽内换行，不缩小文字、不擅改原文、不推移右列。确有用户或原型明确要求的不同结构时，记录例外，不改动无关区域。
- **层级和从属关系可见**：总开关置于所控制设置之前，并以有语义的浅底与下方设置区分；各模块使用库中带小竖条的模块标题。字段标签、编辑内容与次级说明保持不同视觉权重；沿用用户已确认的字重、字号和变量色，不因整理布局回退手动修改。
- **组内与组外操作分别验收**：从 HTML/原型逐项列出组容器、组内条目、输入值、单位、新增、移除及删除组的操作。组外“添加固定任务”不能替代组内“添加技能需求”；可编辑技能和人数不能简化成摘要文字。每个控件用库实例及其属性/文本/显隐实现，保留原型的文案、默认值和控件语义；选择型添加使用选择组件，直接新增使用加号按钮，不混淆两者。
- **关系间距按实际可见内容核验**：强关联内容（控件与说明、条目与新增按钮）为 `8px`，同模块相邻内容组为 `16px`，跨模块为 `24/32px`；单选/多选组内项仍为 `32px`。不仅检查父容器 gap，还要计入组件内已有留白，避免可见距离反而大于下一组；必要时调整外层间距，不破坏原子组件内部规格。行内控件、文字、单位和操作垂直居中；多行标签与内容区顶部对齐。
- **结构与截图双重通过**：逐模块记录标签左边界、内容左/右边界、说明起点及关系间距；检查文本域仍为实例且 Fill 内容列，长文案完整换行、容器随内容增长。补齐嵌套操作后检查全部同级模块及底部操作，不允许空白占位、按钮被遮挡、时间图标或文字被裁剪。只有静态设计入口时，不宣称已实现可运行的新增/删除逻辑。

## 表格与分页

- 表头和行高均为 `44px`；表头/单元格左右内边距 `12px`，图文/控件间距 `10px`，默认列宽 `200px`。
- 表头使用灰 7 背景、`14px / 600`；单元格为 `14px / 400`，正文使用灰 1。底部边框使用表格边框 token。
- 表格支持首列/复选列左冻结、操作列右冻结。仅在实际横向滚动时显示冻结阴影；宽表允许横向滚动。
- 行悬停背景使用灰 7，冻结列背景同步变化。操作链接用信息蓝，文本链接间距约 `12px`。
- 用户列头像 `40×40px`，姓名 `14px / 22px`；不得用随意大小的头像破坏行高。
- 分页右对齐，距表格 `16px`；页码、每页条数选择器、翻页按钮高 `32px`，选择器最小宽 `90px`，激活/悬停使用主色边框或文字。
- 批量选择使用 `SelectionActionBar`：全选所有页、已选数量、取消、确认。不要把业务专属操作硬塞进通用选择条。

## 弹窗与抽屉

- 普通表单对话框常用 `600px`，可选 `480 / 800 / 960px`；简单一句话确认优先用户约定的紧凑 `400px`，目标现有组件若为420px则沿用实例规格，不静默改库母版。视口不足时保证左右至少 `24px` 留白，不把简单确认无故拉到600px。
- 抽屉从右侧出现，常用宽 `800 / 960px`，全高，不设圆角。
- 弹层最大高为视口减 `120px`；正文区域可滚动。头部高 `56px`、左右 `24px`；正文 `0 24px 16px`；底部 `24px`。
- 组合弹窗头部不加下边线，底部操作栏不加上边线。不要额外画分割线伪装组件。
- 弹窗内面向整体任务、流程或安全验证的提示（不属于某个字段），可以使用组件库的通知组件，置于内容区顶部、表单之前；保留组件实例，并按真实提示语义选用样式，不自行添加警告语义。单个字段的说明、格式要求与校验错误仍紧贴对应字段，不提升为整体通知。参考：[安全验证弹窗](https://www.figma.com/design/Sjf6tXsdaGVSrB1Az4TemM?node-id=83-4512)。用户仅要求记录规则时，不重复修改设计稿。
- 使用原底部操作组件：取消/主操作右对齐；验证方式等替代路径切换可放左下角，与右侧按钮垂直居中。隐藏底部操作时仍留40px底部安全距离。仅一句话的Slot无需额外嵌套，复杂表单/双栏才加必要Auto Layout；内容区Fill宽、Hug高，不遗留抽屉前大块空白。

## 导航与图标

- Nav 文案 `14px`；一级菜单图标 `20px`；二级项与一级文字起点对齐。
- 顶栏常用图标统一视觉尺寸 `20px`，用户下拉箭头 `16px`；无论 SVG 或 iconfont 均强制一致。
- 使用已有图标库；不要手绘近似图标或以 Emoji 代替产品图标。
- 普通图标默认沿用全局灰1，品牌/选中/危险等语义优先用对应变量；不能无差别染灰。

## 更改说明与交付标注

- 用户要求变化标注时优先使用指定的 [说明组件34:1448](https://www.figma.com/design/pBXMflBHfznQIDLcDhYqSI?node-id=34-1448) 与 [34:1447](https://www.figma.com/design/pBXMflBHfznQIDLcDhYqSI?node-id=34-1447)，读取实际组件后引用；不把红框箭头等原型评语当产品内容。
- 原文必须保留的还原任务，文案优化建议单独注释“建议改为…”，较大结构/交互优化同步标注。自由度高且待设计师打磨的画板可按用户要求加紫色描边作交付标识，不进入产品。

## 交付前检查

- 页面、导航、侧栏和内容区的滚动分别正确，页面本身不滚动。
- 所有原子控件、表格、弹层和图标复用组件；没有覆盖式自由文本或脱离实例。
- 颜色、字号、间距、圆角、状态均符合本文件或目标 Figma token。
- 筛选、表单、宽表、分页、操作列、长文本在目标 PC 宽度下无裁切或错位。
