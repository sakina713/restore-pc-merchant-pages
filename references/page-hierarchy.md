# 页面层级图布局与连线规范

仅用于设计范围文档的“本次需求页面层级/页面结构图”，不改变业务页面布局，也不把某次需求的业务关系套用到其他需求。

视觉参考：[AI 辅助回款登记 · 页面层级图](https://www.figma.com/design/SJZb0Bb7gxi8pjXlrqAFMZ?node-id=3-228)。参考节点可能被继续编辑，以下文字规则为可移植基线；链接不能替代本次业务关系核对。

## 1. 先确认归属，再排版

- 先记录节点表：`节点标识、原文名称、页面/抽屉/弹窗/能力、新增/修改/复用、来源证据`；再记录连线表：`来源节点、触发动作、目标节点、证据`。
- 新需求以 PRD、原型和源码核对关系；仅调整现有层级图时，读取已有需求分析与节点，保留已确认关系。不能因为两节点相邻就推断跳转。
- **复用能力随实际来源展示**：放在对应页面或弹层的下级，使用灰色节点及连线，不能集中到图外或底部独立“复用能力”区。纯复用仍不单独进入页面明细。
- 例如本次：导入 / 导出、操作日志来自回款明细列表；撤销确认来自查看匹配详情抽屉。此例只解释归属方式，不是其他需求的固定关系。
- 多入口共用能力应保留全部真实入口；为避免交叉，可在各入口下放同名引用节点并标明共用，不能误画成多个新增能力。来源不明先核实，不补无证据的线。

## 2. 统一栅格与视觉层级

- 主路径从左到右，同级主节点顶边与水平中心线一致；业务入口放在首节点上方并与其竖直中心线一致。
- 下级页面按来源分组，同一深度在同一行。来源节点优先位于其子组的水平中心；某子页面还有下级时，继续放在该子页面正下方，不能并入上一层。
- 复用节点与同级新增/修改节点采用一致行高、文字居中和对齐关系，仅以既有灰色样式区分，不降到另一个无关联区域。
- 复用既有节点组件与样式。页面节点默认 `180 × 48px`；短能力节点可 Hug 宽度，但同排高度仍为 `48px`。长名称通过增宽或换行撑高，并同步对齐该排，不压缩字体、不裁切。默认值仅用于该类分析图，不覆盖组件特殊规格或用户指定尺寸。
- 同组节点水平间距建议 `24px`；不同来源组至少 `48px`。相邻层的节点边缘间留 `80–96px` 供连线和动作标注使用。主路径间距由子组宽度决定，不能为了等距挤压分支。
- 保持白色新增、蓝色修改、灰色复用的既有语义；业务入口可沿用模板主色。不得以颜色替代箭头。图例集中在右上，与图例文字垂直居中，不与路径重叠。
- 图内容不足以容纳时，扩展本区宽高并检查父容器回流及后续内容，不缩小整图来塞入原尺寸。不新增装饰卡片或无关分区。

## 3. 连线必须真正连接

- 禁止用自由文本 `→`、`↓` 充当连线；用工具支持的连接器或可编辑矢量路径，保持连续线段和目标端箭头。没有连接器 API 时用矢量路径，不用图片替代。
- 主路径采用水平直线；下级采用竖线或正交折线。一对多分支采用“父节点竖向干线 → 公共水平分支线 → 各子节点竖向箭头”；不同来源不能误用同一条分支线。
- 线宽默认 `1.5px`，使用既有次级灰色变量/样式，箭头约 `6px`。各端点距节点边缘 `4–8px`，避免贴入描边。箭头只在目标端出现。
- 水平线锚点为节点左右边的垂直中心；竖向线锚点为节点上下边的水平中心。不能连接节点角落、停在两个节点之间或穿过节点/文字。
- 动作说明使用次级文本，距所属线段 `8–12px`；同类说明对齐。不要把说明压在线上或与箭头叠放。
- 连线必须显式加入与节点相同的图容器，并核验 `parent`、显隐、裁剪和层叠顺序。不能假设克隆连线后会自动进入正确父级。

## 4. 可重复执行的几何步骤

1. 先按关系表布置全部节点，读取最终矩形 `x、y、width、height`，统一到图容器坐标系；之后再生成连线。节点移动或尺寸变化后必须重新计算相关线段。
2. 计算 `cx = x + width / 2`、`cy = y + height / 2`。主路径用 `源右边 + gap` 至 `目标左边 - gap`；竖向用 `源底边 + gap` 至 `目标顶边 - gap`。分支横线在层间空隙内选定统一 y，保证有空间放动作说明。
3. 矢量路径优先使用非负局部坐标，以路径最小 x/y 为节点原点；箭头尖角也纳入包围盒。避免负坐标导致框架自动归一化，使线段整体偏移 `4px` 等误差。
4. 为连线命名 `来源 → 目标`，分支干线注明来源。对每条连线保留源/目标标识和计算锚点，便于修改与验证；不把临时制作信息写入业务文案。
5. 检查每条线的实际端点与预期锚点偏差不超过 `1px`；同排节点顶边偏差不超过 `1px`；同列父子中心对齐。核对线段与所有无关节点矩形不相交、文字无溢出、全部节点在容器内。

## 5. 交付门禁

- 节点和连线表逐项与输出一一对应；新增/修改/复用属性及页面原文未被排版修改。
- 复用节点均有明确来源和连接，不存在独立复用区、孤立能力或缺失来源的箭头。
- 不存在交叉穿字、无箭头、断线、错位、错误父级、隐藏连线、裁切及同排高度不一致。
- **最后一次修改之后必须重新截图并实际查看**，至少检查整图和最复杂分支；不能只获取截图链接而不查看，也不能复用修改前截图。截图发现问题则修正、重新截图，直到通过才交付。
